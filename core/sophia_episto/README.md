# Sophia Episto

`sophia_episto` is the shared economic planning and reasoning substrate for Sophia.

It is intended to own:

- research plan schemas
- world-model concepts and relationships
- domain playbooks
- methodological lessons
- evaluation and optimization interfaces

It is not intended to own:

- runtime channel orchestration
- direct tool execution
- canonical data writes

See:

- `docs/episto_architecture_spec.md`
- `docs/econ_research_playbook_spec.md`
- `docs/optimizer_autoresearch_integration_spec.md`
